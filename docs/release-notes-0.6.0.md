# 0.6.0

After updating, rebuild the custom-module DLL (Save ship on a ship with custom modules) and install the work tree: most of the new game behaviour (capital-ship jamming, squadron stealth, per-jammer jamming effects, squadron replacement outside Survival, fleet limits) lives in that DLL.

## Fleet limits (DLL options)
- **DLL page → Fleet limits** (`dll patch --skirmish-ships N --fleet-caps A,B --campaign-ships N`, `dll revert` with the flag alone): ships per skirmish / multiplayer fleet, extra skirmish fleet-point caps (default 32,000 and 64,000; the largest is also the fleet save limit), and capital ships per campaign fleet. The custom-module DLL reads them from `StreamingAssets/deadlock-fleet.txt`, so they need no level edits and survive DLL rebuilds; `dll check` lists them. The campaign fleet's single support slot is built into the game and stays at one. See [game/skirmish.md](game/skirmish.md).
- The level-data limits can still be set directly: `shipdb setskirmishinfo maxShips N` (Ship database tools → Fleet limits → Change skirmish fleet size) and `shipdb setfleetinfo MaxShips N`.

## Ships
- **Flak field editor.** Ships tab → Flak field card (`weapons --flak FIELD=VALUE`, values in `--inspect`): flak damage per tick (hull, armour, subsystem, irradiation), distance from the ship, zone length and radius, and bursts per tick, with a to-scale top and side diagram of the zone against the hull (drag its handles to set distance, length and radius), a per-turn damage readout, the Armory's flak damage range and the eight stock flak ships for comparison. How the game uses each field: [game/flak.md](game/flak.md).
- A ship with Jamming now shows it as an installed ability (range and missile chance editable), and its own jamming penalties can be set on the Ships tab (Abilities → Jamming) or with `--jam-speed/--jam-evade/--jam-accuracy`. Every component the ship tools add is now in the installed-ability list, with a test so a new one cannot be left out.
- A ship whose Abilities submenu holds 7 buttons gets a second one ("Abilities 2", button "Other") for further abilities instead of failing to save.
- **Jamming for capital ships.** `weapons --jamming` (Abilities → Jamming on the Ships tab) gives a ship the Cylon Wardriver's Jamming mode: a Jammer that jams enemy squadrons and missiles in range, and a Jamming button. Range (default 500) and missile-jam chance are adjustable; run it again to change them. No ship bundle has these scripts, so the tool writes their MonoScript and type records into the bundle. There is no jam sound. Needs the rebuilt custom-module DLL: the stock game only carries out a Jam order for squadrons, so on a stock DLL a capital ship's jamming switched itself off after one turn. See [game/squadrons.md](game/squadrons.md#jamming-on-capital-ships).

## Munitions
- **Munition damage.** The Armaments munition editor has a Combat section (`shipdb setmunitionstats`): hull, armour and subsystem damage, blast radius, subsystem spread, irradiation, speed, range, guidance accuracy and turn rate, written to the missile prefab the game actually uses. See [game/munitions.md](game/munitions.md#combat-stats).
- **New munition types.** Armaments → Munitions → "Copy as a new munition…" (`shipdb addmunition`) copies a munition as a new type with its own missile prefab, table and icon rows, factory entry, research entries, names and DLL enum member. Edit its stats afterwards; squadrons of the same faction can carry it. See [game/munitions.md](game/munitions.md).

## Squadrons
- The Squadrons tab's Abilities card shows each ability as a collapsible box like the Ships tab: name, menu and slot, and Remove in the header, with the settings as labelled fields inside.
- **Jamming effects per jammer.** Squadrons tab → Jamming effects (`shipdb setjamming`): change the global speed, evasion and accuracy penalty of a jammed ship, or give a squadron type or capital ship its own. The per-jammer values need the rebuilt custom-module DLL (CustomJamming). See [game/squadrons.md](game/squadrons.md#jamming-effects).
- **New squadron types launch.** Carriers only launch squadron types listed on a launch bay; creating a type now adds it to every bay that takes its donor on the carriers allowed to carry it. Types made before this: Launch bays card or `shipdb setsquadronbays`. See [game/squadrons.md](game/squadrons.md#launch-bays).
- **New squadron types.** "Copy and add a squadron type…" on the Squadrons tab (`shipdb addsquadron`) copies a squadron prefab with its table entry, factory entry, optional names and a DLL enum member. See [game/squadrons.md](game/squadrons.md#where-a-squadron-type-lives).
- **Squadron abilities.** Add or remove Board, Disarm, Boost firewalls, Hack, Jamming, Chaff, Paint target, Bomb and Fire munitions on any squadron prefab (Abilities card, `shipdb setsquadronability`). A squadron whose main menu is full (Assault Raptor, Wardriver) gets an Abilities submenu, with one of its main-menu abilities moved into it.
- **Every squadron munition gets a Fire button.** The game pairs Fire munitions buttons with munitions one to one, so a second munition never showed. Saving munitions now adds or removes buttons to match, and gives a squadron with munitions but no Fire munitions ability that ability.
- **Squadron ability settings.** Each ability's settings can be edited in the Abilities card or with `shipdb setsquadronability SQ set ABILITY field=value`: chaff supply, cloud interval and spacing; disarm, hack, jam and paint ranges; hack strength; missile-jam chance; bomb munition and ranges; stealth battery and cooldown.
- **Squadron munitions.** Choose which munition types a squadron carries (Munitions in the Abilities card, `shipdb setsquadronmunitions`). A squadron whose fighter is shared with a squadron type carrying a different number of munitions automatically gets its own copy of the fighter (with its own bundle), so the counts never clash.
- **Squadron research.** Choose which campaigns research a squadron type, its RP cost, the story mission it needs and whether it starts unlocked (Research card, `shipdb setsquadronresearch`). New squadron types can copy their donor's research entries. See [game/squadrons.md](game/squadrons.md#research).
- **Squadron stealth.** Stealth can be added to any squadron like the other abilities (battery, cooldown, active at battle start). Squadrons have no Tech Bay, so the custom-module DLL now includes `CustomStealthFallback`, which gives stealth the Orion's full-health Tech Bay rates on ships without one. Rebuild the custom-module DLL before playing. See [game/squadrons.md](game/squadrons.md#stealth).
- Rebuilding the DLL keeps squadron enum members the same way it keeps copied ship types.

## Custom modules
- **Squadron replacement now works outside Survival.** The custom squadron replacement module used the game's own revive call, which only works in Survival mode. In skirmish and campaign battles destroyed squadrons never came back. The module now docks the squadron itself with one fighter, and hangar repair refills the rest. Rebuild the custom-module DLL (Save ship in the GUI) to get the fix. See [game/squadrons.md](game/squadrons.md#reviving-destroyed-squadrons).
