# Deadlock Tools 0.3.2

This release introduced the standalone Windows x64 edition. Extract `DeadlockTools-Windows-x64.zip` into a writable folder and run `DeadlockTools.exe` to open the editor; Python is bundled. The Python archive is also available for users who prefer to run it with Python installed.

The release assets include the Windows archive and `deadlock.pyz`. The source archive is available from GitHub. Use your own Deadlock game files and donor bundles.
