## Battle UI
- **Ability buttons fit on screen.** When a ship's right-hand battle panel would run off the screen (many squadrons, munitions and abilities, such as the Mercury Mk II), the custom-module DLL lays its ability buttons out in two columns; ships that fit keep the stock single column. Rebuild the custom-module DLL (Save ship) and install it. See [game/battle-ui.md](game/battle-ui.md).
